1. The Hierarchy of Array Optimization

Every optimal array algorithm relies on replacing repetitive iteration with math invariants or dynamic state tracking.

Level 1 $O(N^3)$ Brute

Triple Loop Slicing

Recomputes sums or subarray elements from scratch for every pair $(L, R)$.

sum = 0
for k in range(L, R+1):
  sum += A[k]
Level 2 $O(N^2)$ Carry Forward

Incremental Accumulation

Reuses the sum of subarray $[L..R-1]$ to calculate sum of $[L..R]$ by adding $A[R]$.

curr_sum = 0
for R in range(L, N):
  curr_sum += A[R]
Level 3 $O(N)$ Prefix / Window

Prefix Sums & Windows

Precomputes accumulated state ($P[R] - P[L-1]$) or slides window boundaries in $O(N)$ total time.

# Range Sum
ans = P[R] - P[L-1]
# Sliding: add in, sub out
Level 4 $O(N)$ / $O(1)$ Math

Contribution & Delta Track

Calculates frequency contribution $(i+1)(n-i)$ directly or updates global state in $O(1)$ per query.

# Contribution
sum += A[i]*(i+1)*(n-i)
# Delta: update even_sum

Amortized Analysis Guarantees

Why are variable window and two-pointer algorithms $O(N)$ despite nested loops?

  • ✓ Two-Pointer Guarantee: Right pointer $R$ moves $N$ steps forward. Left pointer $L$ moves at most $N$ steps forward. Total pointer ops: $2N = O(N)$.
  • ✓ Prefix Sum Queries: Preprocessing takes $O(N)$ once. Every subsequent range query requires exactly $1$ subtraction: $O(1)$.
  • ✓ Delta Updates (LC 985): Modifying array elements and updating even sum happens in $O(1)$ per query instead of $O(N)$ sum recomputation.

Prefix Sum & Binary Mapping

Precompute cumulative sums in $O(N)$ time. Range sum for index range $[L..R]$ becomes $P[R] - P[L-1]$ ($O(1)$ time).

💡 Vowel Range Queries:
Convert string to binary array: $1$ if vowel, $0$ otherwise. Build prefix sum on binary array! Range query returns exact vowel count.
def vowel_range_queries(s, queries):
    vowels = {'a', 'e', 'i', 'o', 'u'}
    n = len(s)
    
    # 1. Build binary contribution & prefix sum
    P = [0] * n
    curr = 0
    for i in range(n):
        if s[i] in vowels:
            curr += 1
        P[i] = curr
        
    # 2. Answer queries in O(1)
    ans = []
    for L, R in queries:
        if L == 0: ans.append(P[R])
        else: ans.append(P[R] - P[L - 1])
    return ans

Sum of All Subarrays ($O(N)$ Optimal)

Instead of generating all $O(N^2)$ subarrays, determine how many subarrays contain element $A[i]$.

Formula: total_sum = sum( A[i] * (i + 1) * (n - i) )
Time: O(N) | Space: O(1) 
def sum_all_subarrays(A):
    n = len(A)
    total_sum = 0
    
    for i in range(n):
        occurrences = (i + 1) * (n - i)
        total_sum += A[i] * occurrences
        
    return total_sum

LC 985: Even Sum After Queries

Given array and queries `[val, index]`. Update element and return sum of even numbers after each query.

Delta Trick: Compute initial sum of evens. On query, if old value was even, subtract it from sum. Add new value to array. If new value is even, add it to sum! $O(1)$ query processing. 
def sumEvenAfterQueries(nums, queries):
    even_sum = sum(x for x in nums if x % 2 == 0)
    ans = []
    
    for val, idx in queries:
        # Deduct old value if it was even
        if nums[idx] % 2 == 0:
            even_sum -= nums[idx]
            
        nums[idx] += val
        
        # Add new value if it is even
        if nums[idx] % 2 == 0:
            even_sum += nums[idx]
            
        ans.append(even_sum)
    return ans

LC 31: Next Permutation

Rearrange numbers into lexicographically next greater permutation in-place ($O(N)$ time, $O(1)$ space).

⚠ 3-Step Algorithm:
1. Find dip index from back where $A[i] < A[i+1]$.
2. If no dip, reverse whole array (was strictly decreasing).
3. If dip found, swap $A[idx]$ with next largest from back, then reverse suffix from $idx+1$ to end.
def nextPermutation(nums):
    n = len(nums)
    idx = -1
    # 1. Find dip from back
    for i in range(n - 2, -1, -1):
        if nums[i] < nums[i + 1]:
            idx = i
            break
            
    if idx == -1:
        nums.reverse(); return
        
    # 2. Find element > nums[idx] from back
    for i in range(n - 1, idx, -1):
        if nums[i] > nums[idx]:
            nums[i], nums[idx] = nums[idx], nums[i]
            break
            
    # 3. Reverse suffix
    nums[idx + 1:] = reversed(nums[idx + 1:])

Fixed & Variable Sliding Windows

Avoid recomputing overlapping contiguous regions by adding incoming elements and removing outgoing elements. 

def max_subarray_sum_k(A, k):
    curr = sum(A[:k])
    max_s = curr
    for i in range(k, len(A)):
        curr += A[i] - A[i - k]
        max_s = max(max_s, curr)
    return max_s

LC 75: Sort Colors (Dutch Flag)

Partition array of 0s, 1s, and 2s in a single pass using 3 pointers (`L`, `mid`, `R`). 

def sortColors(nums):
    L, mid, R = 0, 0, len(nums) - 1
    while mid <= R:
        if nums[mid] == 0:
            nums[L], nums[mid] = nums[mid], nums[L]
            L += 1; mid += 1
        elif nums[mid] == 1:
            mid += 1
        else:
            nums[mid], nums[R] = nums[R], nums[mid]
            R -= 1  # Do NOT advance mid here!
