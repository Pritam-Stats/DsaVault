1. The Evolution of Optimization: Subarray Sums

Understanding why sliding windows exist requires seeing how brute force solutions recompute identical calculations unnecessarily.

Level 1 O(N³) Time

Brute Force Triple Loop

Generates every start point L and end point R, then iterates over every element between them to sum.

for L in range(N):
  for R in range(L, N):
    sum = 0
    for k in range(L, R+1): sum += A[k]
Level 2 O(N²) Time | O(N) Space

Prefix Sum Array

Precomputes accumulated sums in memory. Sum from L to R becomes a simple subtraction: P[R] - P[L-1].

P = precompute_prefix(A)
for L in range(N):
  for R in range(L, N):
    sum = P[R] - P[L-1]
Level 3 O(N²) / O(N) Sliding

Carry Forward & Sliding Window

Maintains running state on the fly. As the right edge advances, add A[R] and subtract A[L-1] without restarting.

# First Principle of Sliding
for L in range(N):
  curr_sum = 0
  for R in range(L, N):
    curr_sum += A[R]

Why are Variable Windows O(N) despite Nested Loops?

A common interview trap is assuming a while loop inside a for loop automatically equals O(N²). Here is the formal Amortized Analysis.

The Two-Pointer Invariant

In a variable window, the outer pointer R moves from 0 to N-1 (exactly N steps). The inner pointer L only moves forward, never backward.

  • ✓ R Pointer: Incremented exactly N times in the main loop.
  • ✓ L Pointer: Starts at 0 and can at most reach N-1 across the entire execution of the algorithm.
  • ✓ Total Pointer Operations: At most N (for R) + N (for L) = 2N = O(N).
Key Takeaway for Technical Interviews: Do not count iterations per outer loop turn. Count the total lifetime operations of the pointers!

Max Subarray Sum of Size K

Given an integer array A and size K, find the maximum sum among all contiguous subarrays of length K.

★ Core Sliding Window Template:
1. Pre-calculate sum of the first window [0...K-1].
2. Slide from index K to N-1: add A[i], subtract A[i-K].
def max_subarray_sum(A, k):
    # 1. Build initial window
    window_sum = sum(A[:k])
    max_sum = window_sum
    
    # 2. Slide window across array
    for i in range(k, len(A)):
        window_sum += A[i] - A[i - k]  # Add incoming, drop outgoing
        max_sum = max(max_sum, window_sum)
        
    return max_sum

Count Distinct Elements in Subarrays of Size K

Tracks unique element counts in every window of size K using a Hash Map frequency counter.

⚠ CRITICAL ENGINE PITFALL:
When an element's count reaches 0 after sliding out, you MUST explicitly delete key from hash map! Otherwise len(map) will incorrectly include 0-frequency keys.
def count_distinct_elements(A, k):
    counts = {}
    ans = []
    
    for i in range(k):
        counts[A[i]] = counts.get(A[i], 0) + 1
    ans.append(len(counts))
    
    for i in range(k, len(A)):
        counts[A[i]] = counts.get(A[i], 0) + 1
        counts[A[i-k]] -= 1
        if counts[A[i-k]] == 0:
            del counts[A[i-k]]  # CRITICAL cleanup!
        ans.append(len(counts))
        
    return ans

Longest Subarray with Sum <= X

Variable window pattern. Expand R pointer to grow window. When constraint is violated (sum > X), shrink from left by advancing L pointer until valid.

Window Length Formula: R - L + 1
Shrink Condition: sum > X 
def longest_subarray(A, x):
    L = 0
    curr_sum = 0
    max_len = 0
    
    for R in range(len(A)):
        curr_sum += A[R]
        
        # Shrink window from left until valid
        while curr_sum > x and L <= R:
            curr_sum -= A[L]
            L += 1
            
        max_len = max(max_len, R - L + 1)
    return max_len

LC 977: Squares of a Sorted Array

Given array sorted in non-decreasing order with negatives. Return sorted squares in O(N).

💡 Mathematical Insight:
Due to negative numbers, the largest squares are guaranteed to be at the extremes (far left or far right). Fill the result array back-to-front!
def sortedSquares(nums):
    n = len(nums)
    res = [0] * n
    L, R = 0, n - 1
    
    # Fill from back to front
    for i in range(n - 1, -1, -1):
        if abs(nums[L]) > abs(nums[R]):
            res[i] = nums[L] ** 2
            L += 1
        else:
            res[i] = nums[R] ** 2
            R -= 1
    return res

LC 88: Merge Sorted Array In-Place

Merge nums2 into nums1 as one sorted array. nums1 has size m+n with trailing zero buffer space.

Engineering Edge Case: Merging from front overwrites unprocessed elements in nums1. Always compare and fill backwards from index m+n-1! 
def merge(nums1, m, nums2, n):
    i, j, k = m - 1, n - 1, m + n - 1
    
    while i >= 0 and j >= 0:
        if nums1[i] > nums2[j]:
            nums1[k] = nums1[i]
            i -= 1
        else:
            nums1[k] = nums2[j]
            j -= 1
        k -= 1
        
    # Fill remaining elements from nums2 if any
    while j >= 0:
        nums1[k] = nums2[j]
        j -= 1
        k -= 1

LC 75: Sort Colors (Dutch National Flag)

Partition array of 0s, 1s, and 2s in-place in a single pass using 3 pointers (L, mid, R).

⚠ CRITICAL POINTER TRAP:
When nums[mid] == 2, swap with R and decrement R. DO NOT increment mid! The value swapped from R is unexamined and must be checked on the next iteration.
def sortColors(nums):
    L, mid, R = 0, 0, len(nums) - 1
    
    while mid <= R:
        if nums[mid] == 0:
            nums[L], nums[mid] = nums[mid], nums[L]
            L += 1
            mid += 1
        elif nums[mid] == 1:
            mid += 1
        else:  # nums[mid] == 2
            nums[mid], nums[R] = nums[R], nums[mid]
            R -= 1  # DO NOT advance mid here!
